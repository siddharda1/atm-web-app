# ATM Web App

A simple ATM simulation web application built using Streamlit.



-  User Login (Card Number & PIN)
-  Check Balance
-  Deposit Money
-  Withdraw Money
-  Change PIN
-  Clean UI with sidebar

##  Tech Stack

- Python
- Streamlit

## Live Demo

👉 https://atm-web-app.streamlit.app

##  How to Run Locally

```bash
pip install streamlit
streamlit run atm_web.py
